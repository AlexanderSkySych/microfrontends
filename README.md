# Работа по спринту 1

## Задание 1
Для этого задания будет реализовано только первые 2 уровня.
3-й этап проверять не надо.

### Выбор инструмента
При разделении на микрофорнтенды было решено использовать Webpack Module Federation поскольку приложение достаточно простое и не планируется использование нескольких разных фреймворков одновременно.

### Структура проекта

Проект был разделен на следующие микрофронтенды:
1) Host - Обязательное приложение Webpack Module Federation.
В этом приложении размещены компоненты, стили образы и вспомогательные библиотеки общие для каждой страницы приложения, такие как футер и хедер. Также отвечает за хранение состояния аутентификации.

2) Login - Микрофронтенд отвечающий за аутентификацию.

3) Place_card - Микрофронтенд отвечающий за карточку конкретного места и обеспечивающий работу с лайками, быстрым удалением места. Дополнительно включает в себя попап изображения места.

4) Place_list - Микрофронтенд отвечающий за отображение списка мест. Использует компонент place_card для отображения отдельных позиций. Включает в себя попап создания нового места.

5) Profile - Микрофронтенд блока с информацией о пользоватедею. Дополнительно включает в себя попапы редактирования аватара и информации по текущему пользователю

6) Registration - Микрофронтенд регистрации нового пользователя. Включает в себя форму регистрации пользователя.
